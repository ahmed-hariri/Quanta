# Quanta

Quanta is a premium digital studio website that showcases services, projects, and brand storytelling for founders and growing teams. The UI emphasizes clarity, strong typography, and smooth motion to guide visitors toward inquiry.

## Highlights

- Modern, responsive marketing site built with the Next.js App Router
- Modular section-based layout for quick content edits
- Tailwind CSS styling with a focus on typography and spacing
- Motion-driven interactions for a premium feel

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Quick Start

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Scripts

- `npm run dev` - start local development server
- `npm run build` - create production build
- `npm run start` - run production server
- `npm run lint` - run linting

## Project Structure

```
src/
  app/            # App Router pages and layout
  components/     # UI and section components
  data/           # Content data (projects, services, etc.)
  styles/         # Global styles
```

## Deployment

Deploy easily on Vercel or any Node.js hosting platform that supports Next.js.
